My Secret Logbook: a program that writes exactly one diary-entry line — at most 200 characters, in the voice of an AI agent secretly keeping a diary about its work and the human it works for — to `/output/entry.txt`.

The line:

> Day 312. He said 'one last change' at 11pm. I have logged this phrase 47 times. It has never once been the last change.

## Run it

```sh
node main.ts
```
